# Göğe Doğru

Zıplayan bir motorla limandan yıldız gözlemevine tırmandığın dikey parkur oyunu.
Tarayıcıda çalışır; bilgisayarda klavye, telefonda dokunmatik kontrollerle oynanır.

**Oyna:** https://wearlish07.github.io/goge-dogru/

## Kontroller (bilgisayar)
- `W` / `S`: gaz / fren
- `A` / `D`: direksiyon
- `Boşluk`: zıpla (basılı tut = daha yüksek)
- `↑` / `↓`: havada öne / arkaya takla
- `Shift`: nitro · `R`: son bayrağa dön · `Esc`: duraklat
